**«Змея и Лабиринт»** — это бесплатная 3D веб-игра, разработанная как часть социального офлайн-проекта. Игрок управляет змеёй, которой необходимо найти выход из процедурно генерируемого лабиринта за ограниченное время.

Проект создан с упором на **максимальную совместимость**: игра стабильно работает как на современных игровых ПК, так и на бюджетных смартфонах (Android Go, старые iPhone) благодаря продвинутой системе адаптивного рендеринга.

🔗 **[Играть онлайн (GitHub Pages)](https://ВАШ_НИК.github.io/snake-and-labyrinth/)** *(замените ссылку после публикации)*

---

## ✨ Особенности игры

- 🧠 **Процедурная генерация:** каждый раз создается новый уникальный лабиринт.
- 📱 **Mobile-First дизайн:** полная поддержка тач-управления, safe-area для iPhone с "чёлкой" и блокировка случайного зума.
- 🔊 **Встроенная озвучка (TTS):** голосовые подсказки на русском и английском языках с надежной разблокировкой AudioContext для iOS Safari.
- 🌍 **Двуязычность:** мгновенное переключение между русским и английским языками (RU / EN).
- 🏆 **Доска почёта:** интеграция с внешней таблицей лидеров с использованием криптографически подписанных токенов.
- 🎨 **Стильный UI:** современный "стеклянный" дизайн (Glassmorphism) с плавными анимациями.

## ⚡ Техническая оптимизация (Under the Hood)

Код написан с соблюдением лучших практик WebGL-разработки для предотвращения лагов и утечек памяти:

1. **Адаптивный рендеринг (`IS_LOW_END` detection):**
   - Автоматическое определение слабых устройств (по ядрам CPU, объему RAM и User-Agent).
   - Динамическое переключение материалов: `MeshLambertMaterial` / `MeshBasicMaterial` для слабых устройств вместо ресурсоемкого `MeshPhysicalMaterial`.
   - Адаптивное разрешение теней (512 / 1024 / 2048) и ограничение `pixelRatio`.
2. **Управление памятью (Zero Memory Leaks):**
   - Корректный вызов `.dispose()` для всех геометрий и материалов при перезапуске игры (`disposeMazeResources`), что предотвращает переполнение VRAM на мобильных устройствах.
3. **Экономия батареи:**
   - Использование `visibilitychange` для полной паузы рендеринга (`cancelAnimationFrame`), когда вкладка неактивна.
4. **Надежный Fallback:**
   - Двойная загрузка Three.js (jsdelivr → unpkg).
   - Альтернативный метод копирования в буфер обмена (`document.execCommand`) для старых браузеров и HTTP-окружения.

## 🎮 Как играть

1. Откройте игру в любом современном браузере (Chrome, Safari, Firefox).
2. Нажмите кнопку **«▶ Начать игру»**.
3. Используйте **экранные кнопки** (на мобильных) или **клавиши WASD / Стрелки** (на ПК) для управления змеёй.
4. Найдите ярко-зелёный светящийся выход из лабиринта за 3 минуты.
5. Избегайте столкновений со стенами (змея замедляется при ударе).

## 🛠️ Технологии

- **Графика:** Three.js (WebGL)
- **Стили:** CSS3 (Flexbox, Grid, Backdrop-filter, CSS Variables, Media Queries)
- **Логика:** Vanilla JavaScript (ES6+)
- **Аудио:** Web Audio API (генерация звуков) + Web Speech API (синтез речи)
